UNDANGAN PERNIKAHAN MAJID & BELA

Tema:
Sage Green + Ivory + Champagne Gold — Elegant Garden

Isi:
- Sampul menggunakan foto pertama
- Foto mempelai pria menggunakan foto kedua
- Foto mempelai wanita menggunakan foto ketiga
- Foto berikutnya digunakan sebagai galeri
- Countdown menuju akad 23 Agustus 2026 pukul 08.00 WIB
- Akad 08.00 WIB
- Resepsi 09.00 WIB – selesai
- Tombol Google Maps dengan alamat yang diberikan
- Galeri dengan tampilan lightbox
- Bagian "Kisah Kami" tidak digunakan
- Biodata lengkap kedua mempelai, termasuk tanggal lahir, urutan anak, nama orang tua, dan Instagram

CARA UPLOAD KE GITHUB:
1. Extract ZIP.
2. Upload index.html dan style.css ke repository.
3. Buat folder "images", lalu upload semua 8 gambar ke dalam folder images.
4. Upload script.js.
5. Commit semua perubahan.
6. Pastikan nama file dan folder persis seperti ini:

index.html
style.css
script.js
images/
  sampul.jpg
  mempelai-pria.jpg
  mempelai-wanita.jpg
  galeri-1.jpg
  galeri-2.jpg
  galeri-3.jpg
  galeri-4.jpg
  galeri-5.jpg

Catatan:
Alamat Google Maps dibuat berdasarkan alamat teks yang diberikan. Jika nanti Anda mempunyai link Google Maps yang tepat, link tombol bisa diganti agar langsung menuju titik lokasi acara.


Versi ini sudah dirapikan untuk tampilan HP: jarak, tipografi, kartu biodata, galeri, sampul, dan tombol dibuat lebih konsisten.
